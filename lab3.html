Завдання №1: Вдосконалення макету власного сайту

У цій частині роботи я повністю переробив свій каталог ігрових модифікацій, зробивши його сучасним та адаптивним.

Пояснення щодо макету та адаптивності:

Для свого сайту я обрав гумовий (еластичний) тип макету з використанням технології Flexbox. Основний контейнер має обмеження по максимальній ширині (`max-width: 1200px`), щоб на дуже великих екранах сайт не розтягувався до безкінечності, але при звуженні вікна браузера весь контент плавно стискається завдяки відносним одиницям вимірювання (наприклад, `%`, `vh`, `rem`).

Адаптивність реалізована за допомогою медіа-запитів (`@media`):

  • Десктоп (великі екрани): Шапка, контент (бокове меню + картки модів) та футер вишикувані в ряд (Flex Row). Бокове меню займає фіксовані 250px.
  • Планшет (ширина до 992px): Бокове меню переміщується нагору, над основним контентом (`flex-direction: column`), щоб не забирати дорогоцінне місце збоку. Шапка стає гнучкішою. З'являється кнопка бургер-меню.
  • Смартфон (ширина до 768px): Навігаційне меню ховається і відкривається лише по кліку на бургер-меню (через JavaScript). Колонки футера стають одна під одною. Картинки в картках модів збільшуються на всю ширину екрану для кращої видимості.

Скріншот головної сторінки:

HTML-код головної сторінки (`index.html`):

<!-- Код знаходиться в репозиторії appWEB -->
<header class="header">
    <div class="logo">ModPlatform</div>
    <button class="burger-menu" id="burger-btn" aria-label="Відкрити меню">
        <span></span><span></span><span></span>
    </button>
    <nav class="main-nav" id="main-nav">
        <a href="index.html">Каталог</a>
        <a href="about.html">Про проєкт</a>
    </nav>
</header>
<!-- Інший код див. у репозиторії -->

CSS-код адаптивності (`style.css`):

@media (max-width: 992px) {
    .content-wrapper { flex-direction: column; }
    .sidebar { flex: 0 0 auto; width: 100%; border-right: none; border-bottom: 1px solid #e0e0e0; padding-right: 0; padding-bottom: 1.25rem; }
    /* ... */
}
@media (max-width: 768px) {
    .burger-menu { display: flex; /* ... */ }
    .main-nav { display: none; flex-direction: column; /* ... */ }
    .main-nav.active { display: flex; animation: fadeIn 0.3s ease-in-out; }
    /* ... */
}

Завдання №2: Макетна верстка. Фіксована таблична (Варіант 2)

У цьому макеті структура сторінки (шапка, колонки, підвал) задана за допомогою тегу <table>. Ширина макету жорстко зафіксована у 800px. Перевага такого підходу — простота та гарантія того, що колонки не роз'їдуться. Недолік — макет не адаптується під екрани мобільних пристроїв, з'являється горизонтальна прокрутка.

Завдання №2: Макетна верстка. Гумова таблична (Варіант 2)

Тут також використовується <table>, але ширина задана у відсотках (width: 100%). Завдяки цьому макет розтягується або стискається залежно від розміру вікна браузера. Це краще, ніж фіксований макет, але на дуже великих екранах рядки тексту можуть стати занадто довгими і незручними для читання.

Завдання №2: Макетна верстка. Фіксована блокова (Варіант 3)

Макет побудований на тегах <div> із застосуванням властивості float для розміщення колонок поруч одна з одною. Ширина макету фіксована (800px). Це більш семантично правильний підхід, ніж таблиці (які мають використовуватися для даних, а не для дизайну), але float вимагає додаткових "костилів" на кшталт clear: both для футера, щоб він не наїжджав на колонки.

Завдання №3: Верстка FLEXBOX (Варіант 1)

У цьому завданні я зверстав фрагмент лендінгу, використовуючи виключно сучасну технологію Flexbox (display: flex). Це значно спрощує вирівнювання елементів по вертикалі та горизонталі, створення сіток карток та адаптацію під різні екрани без використання застарілих float.

🔗 Жива сторінка макету: Переглянути сторінку на Flexbox

Особливості макету:

  • Використано justify-content: space-between для рівномірного розподілу карток та елементів навігації.
  • Картки мають однакову висоту завдяки flex: 1.
  • За допомогою властивості order реалізовано чергування зображень та тексту в секції "Для кого розроблена програма".
  • Для ефектів "зрізаних кутів" на фотографіях використано сучасну CSS-властивість clip-path: polygon(...).
  • Макет повністю адаптивний: на планшетах картки стають по дві в ряд, а на мобільних — по одній.

Висновки

Під час виконання третьої лабораторної роботи я на практиці переконався, як сильно еволюціонувала верстка веб-сторінок. Спершу я спробував верстати макети таблицями та застарілим методом через `float` — це працює, але вимагає зайвого коду і складно адаптується під мобільні пристрої. Потім я перевів свій власний сайт на Flexbox і застосував медіа-запити (`@media`). Це дозволило зробити дизайн по-справжньому гнучким, зручним для перегляду з телефону (з бургер-меню) та сучасним. Flexbox — це однозначно найкращий інструмент для побудови структури сайту на сьогодні.
