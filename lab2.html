Способи підключення стилів

Загалом є три способи додати CSS до HTML-сторінки:

  1. Внутрішні (inline): пишемо стилі через атрибут style="..." прямо всередині тегу.
  2. Глобальні (internal): додаємо CSS-код всередині тегу <style> у блоці <head>.
  3. Зовнішні (external): виносимо всі стилі в окремий файл .css і підключаємо його (саме так я зробив у своєму проєкті).

Селектори тегу

Цей селектор застосовує стилі одразу до всіх однакових тегів на сторінці. Наприклад, я задав загальний шрифт та фон для всього body.

HTML-код

<body> ... </body>

CSS-код

body {
    font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
    background-color: #f8f9fa;
}

Селектори класу

Клас позначається крапкою (.). Він дозволяє зручно стилізувати конкретні блоки, яким ми задали цей клас. Я використав його для головного контейнера.

HTML-код

<main class="container"> ... </main>

CSS-код

.container {
    max-width: 1200px;
    background-color: #ffffff;
}

Селектори ідентифікаторів

Ідентифікатор пишеться через решітку (#). Він унікальний і використовується для одного конкретного елемента на сторінці, наприклад, для кнопки пошуку.

HTML-код

<button type="submit" id="search-btn">Знайти</button>

CSS-код

#search-btn {
    background-color: #2563eb;
    color: white;
}

Інші селектори

  • Універсальний (*): * { box-sizing: border-box; } — застосовує правило до абсолютно всіх елементів на сторінці.
  • Дочірній (>): .main-nav > a { color: #555; } — діє тільки на ті елементи, які є прямими нащадками (у моєму випадку це посилання в меню).
  • Сусідній (+): .sidebar h2 + ul { margin-top: 15px; } — стилізує список, який йде рівно після заголовка H2.
  • За атрибутом ([]): input[type="text"] { border-radius: 4px; } — дозволяє вибрати поле вводу саме текстового типу.

Шрифти, фон, контур, списки та просунутий CSS

Шрифти та текст: Задав базовий шрифт 'Segoe UI', налаштував жирність та колір тексту для заголовків.

Фон: Для всієї сторінки зробив приємний світло-сірий фон #f8f9fa.

Контур: Налаштував поле пошуку так, щоб при кліку на нього з'являлася синя рамка (стан :focus).

Списки: Змінив стандартні маркери для багаторівневих списків на квадратики та кружечки за допомогою list-style-type.

Просунуті фічі: Додав легку тінь для головного блоку (box-shadow), а для кнопки "Знайти" зробив плавну зміну кольору при наведенні курсору (transition).
